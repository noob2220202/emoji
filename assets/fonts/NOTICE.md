# 폰트 출처 / 라이선스

`/text` 글자 이모지화 기능에서 쓰는 폰트들은 모두 [Google Fonts](https://fonts.google.com)에서
받은 것으로, [SIL Open Font License 1.1](https://openfontlicense.org/)(`OFL.txt` 참고)로
배포됩니다. OFL은 폰트를 자유롭게 사용/수정/재배포할 수 있게 허용하는 라이선스입니다
(단, 폰트 파일 자체를 판매하는 것은 금지됩니다).

| 파일 | 폰트 이름 | Google Fonts 페이지 |
|---|---|---|
| `BlackHanSans-Regular.ttf` | Black Han Sans | https://fonts.google.com/specimen/Black+Han+Sans |
| `Jua-Regular.ttf` | Jua | https://fonts.google.com/specimen/Jua |
| `DoHyeon-Regular.ttf` | Do Hyeon | https://fonts.google.com/specimen/Do+Hyeon |
| `NanumPenScript-Regular.ttf` | Nanum Pen Script | https://fonts.google.com/specimen/Nanum+Pen+Script |

각 폰트 패밀리별 정확한 저작권자 정보는 위 Google Fonts 페이지 또는
[google/fonts 저장소](https://github.com/google/fonts)의 각 폰트 디렉터리에 있는 `OFL.txt`를 참고하세요.
